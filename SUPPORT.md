# Support

- Questions, ideas and show-and-tell: [GitHub Discussions](https://github.com/glschaefer09-ux/syrebrum-core/discussions).
- Bugs: open a GitHub issue. Don't include secrets or private data.
- Security problems: see [SECURITY.md](SECURITY.md). Don't use public issues.
- Supported version: the latest 0.1.x release. Fixes ship as new patch releases.
- Commercial support and products: https://syrebrum.com
